# RustyChain

A high-performance, type-safe Rust library for building LLM-powered applications.

## Installation

Add RustyChain to your project using Cargo:

```bash
cargo add rustychain
```

Add to your `Cargo.toml`:

```toml
[dependencies]
rustychain = "0.0.1"
```
